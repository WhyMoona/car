# Бортжурнал — блокнот автомобилиста в Telegram

Mini App для Telegram: машины, заправки, расходы, расход топлива, напоминания и статистика.
Без своего сервера: данные лежат в облаке Telegram (CloudStorage) у каждого пользователя, копия — на устройстве.

## Что внутри

```
index.html            — страница приложения
app.bundle.js         — весь код одним файлом (собирается из js/ командой node build.mjs)
icon.svg              — логотип
css/app.css           — оформление
js/app.js             — запуск
js/config.js          — ИМЯ БОТА и версия (поменяйте под себя)
js/i18n/ru.js         — все тексты интерфейса (для нового языка — копия этого файла)
js/tg.js              — работа с Telegram (кнопки, вибрация, полноэкранный режим)
js/core/              — расчёты, хранение, фото, экспорт (без интерфейса)
js/ui/                — экраны и элементы интерфейса
tests/                — тесты расчётов и хранения
build.mjs             — сборка app.bundle.js (без сторонних пакетов)
.github/workflows/    — автопубликация на GitHub Pages
```

Исходный код лежит в `js/`, а страница подключает собранный `app.bundle.js`. После правок в `js/` выполните `node build.mjs` (или просто отправьте изменения на GitHub — сборка запустится там сама).

## Проверить у себя на компьютере

Просто откройте `index.html` двойным щелчком — приложение запустится в демо-режиме: внизу появится синяя кнопка вместо кнопки Telegram, а «облако» имитируется в браузере. Так же оно работает на `http://localhost`.

Тесты (нужен Node.js 18+): `npm test`

## Публикация: пошагово для новичка

### 1. Создайте репозиторий на GitHub

1. Зарегистрируйтесь на https://github.com (если ещё нет аккаунта).
2. Справа вверху «+» → **New repository**.
3. Название, например `bortjournal`. Видимость — **Public** (бесплатный GitHub Pages работает с публичными репозиториями).
4. Нажмите **Create repository**.

### 2. Загрузите файлы

**Вариант А — через сайт (без программ):**
1. В новом репозитории нажмите **uploading an existing file**.
2. Перетащите всё содержимое папки проекта: `index.html`, `app.bundle.js`, `icon.svg`, `build.mjs`, `package.json`, `README.md` и папки `css`, `js`, `tests`.
3. Внизу нажмите **Commit changes**.
4. Папку `.github` браузер может не увидеть (она скрытая). Создайте файл вручную: **Add file → Create new file**, в поле имени введите `.github/workflows/deploy.yml`, вставьте содержимое одноимённого файла из проекта, **Commit changes**.

**Вариант Б — через git:**
```
cd bortjournal
git init
git add .
git commit -m "Первая версия"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/bortjournal.git
git push -u origin main
```

### 3. Включите GitHub Pages

1. В репозитории: **Settings → Pages**.
2. В разделе **Build and deployment → Source** выберите **GitHub Actions**.
3. Откройте вкладку **Actions** — там запустится «Deploy». Если он не стартовал сам, выберите его слева и нажмите **Run workflow**.
4. Через 1–2 минуты появится зелёная галочка. Адрес приложения:
   `https://<ваш-логин>.github.io/bortjournal/`

Откройте его в браузере — должна появиться страница «Это приложение работает в Telegram». Так и задумано. Если вместо этого написано «Не получилось запустить» — на экране будет указано, какого файла не хватает.

### 4. Создайте бота и подключите приложение

1. В Telegram откройте **@BotFather** → `/newbot`.
2. Введите имя (например, «Бортжурнал») и username, который заканчивается на `bot` (например, `my_bortjournal_bot`).
   Токен бота сохраните у себя, **но никуда в проект его не вставляйте** — приложению он не нужен.
3. Главное мини-приложение: `/mybots` → ваш бот → **Bot Settings** → **Configure Mini App** → **Enable Mini App** → пришлите адрес из шага 3.
   Теперь в профиле бота появится кнопка «Открыть», а ссылка `https://t.me/<username_бота>?startapp` сразу открывает приложение.
4. Кнопка меню в чате: `/mybots` → ваш бот → **Bot Settings** → **Menu Button** → пришлите тот же адрес и подпись кнопки, например «Открыть».
5. Впишите username бота (без @) в `js/config.js` в строку `BOT_USERNAME: ''` и закоммитьте — тогда на странице для обычного браузера появится кнопка «Открыть в Telegram».

Названия пунктов в BotFather иногда немного меняются — если не нашли, ищите в меню бота разделы про Mini App / Menu Button.

### 5. Как обновлять приложение

Меняете файлы → загружаете в репозиторий (через сайт: открыть файл → карандаш → **Commit changes**; через git: `git add . && git commit -m "..." && git push`).
GitHub Actions сам прогонит тесты и опубликует новую версию за 1–2 минуты. Если тесты упали, публикация не произойдёт — старая версия продолжит работать.

Telegram может закешировать старую версию: закройте мини-приложение и откройте снова (на телефоне иногда нужно подождать пару минут).

Если меняете формат данных, увеличьте `DATA_VERSION` в `js/core/model.js` и добавьте миграцию в `MIGRATIONS` — старые записи пользователей обновятся автоматически.

## Как хранятся данные

- **Облако Telegram (CloudStorage)** — привязано к пользователю и боту, синхронизируется между устройствами, другие люди его не видят. Лимиты: 1024 ячейки по 4096 символов. Данные сжимаются и раскладываются по годам; большие документы делятся на части. Сначала пишутся новые части, затем «оглавление», затем удаляются старые — обрыв связи не портит сохранённое.
- **localStorage** — копия на устройстве: приложение открывается мгновенно, а запись, сделанная без интернета, уйдёт в облако при следующей возможности.
- **Фото** сжимаются на телефоне (до 800 px, ~75 КБ), хранятся в IndexedDB и копией в облаке (~25 ячеек на фото). Если место в облаке кончится, фото останется только на этом устройстве — приложение об этом сообщит.
- **Экспорт** (Настройки): JSON с фото — для восстановления, CSV — для Excel. Если телефон не даёт сохранить файл, используйте «Скопировать JSON» и вставьте текст в заметки или себе в «Избранное».
